ZeroDivisionError em Python

Erro: Não é possível dividir por zero (ZeroDivisionError).

Em Python, uma divisão por zero gera uma exceção nativa. O bloco try...except intercepta essa falha para que o programa não feche abruptamente!

Como este cálculo se parece no código Python:
resultado = porcentagem(200, 15) # -> 15% de 200 = 30

Os 4 Pilares da sua Calculadora

1. Funções e Modularidade (def)

Cada operação matemática é isolada em sua própria função com anotações de tipo (Type Hints). Isso organiza o código e permite que cada função seja testada independentemente. 

def porcentagem(valor: float, taxa: float) -> float:
    return (valor * taxa) / 100.0

2. Tratamento de Erros (try...except)

Divisão por zero e digitação de letras em vez de números são interceptadas com ZeroDivisionError e ValueError, garantindo que o programa nunca quebre no meio do uso. 

try:
    resultado = divisao(num1, num2)
except ZeroDivisionError as err:
    print(f"Erro: {err}")

3. Conversão de Tipos (Casting)

A função input() sempre retorna texto (str). A função float(...) converte o texto para número decimal antes do cálculo aritmético. 

num1 = float(input("Digite: "))

4. Laço Contínuo (while True)

Mantém o menu aberto na tela para que o usuário possa fazer vários cálculos seguidos, até escolher explicitamente a opção 6. Sair (break). 

while True:
    exibir_menu()
    if opcao == "6":
        break
